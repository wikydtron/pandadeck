# Changelog

## 0.6.5: first public release

**Panel firmware**
- Pages: AI, DECK, MUSIC, HUD, with an optional soundboard tab; hold the clock to flip the screen.
- USB-C: HID keyboard and media keys plus a framed CDC link to the app (plug and play);
  Wi-Fi API with token auth and over-the-air updates with automatic rollback.
- Deck in two styles (classic cards, phone-style icons), real app icons, F13–F24 macros.
- Music: cover art, blurred cover or artist-photo backdrop, seek, shuffle/repeat, ❤ Like.
- HUD: CPU/GPU/temperatures/memory/disk/network for the PC and an optional homelab with Docker.
- Smooth 800×480 rendering: 64 KB data cache, IRAM-safe RGB ISR, ping-pong image buffers.

**Desktop app (Windows, macOS, Linux)**
- Tray icon and settings page; finds the panel over USB, falls back to Wi-Fi.
- Most-used apps, files, folders and websites on the deck; custom pages and macros.
- Now playing from the system (GSMTC, MPRIS, AppleScript) or Spotify (your own Client ID).
- Soundboard with built-in effects, sounds from files or links, automatic meme pictures, and
  button pictures generated by your own Codex or Claude Code.
- Optional AI page: Claude Code / Codex sessions, usage limits, Approve / Deny on the panel.

**Hardware**
- A free 3D-printable desk stand built around BTT's magnetic dock, on MakerWorld.
