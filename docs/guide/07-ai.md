# 7. The AI page (optional)

If you use **Claude Code** or **OpenAI Codex**, PandaDeck can be their mission control:

* every running session, live — *working*, *your turn*, or *waiting for permission*
  (Claude in clay, Codex in blue),
* your **usage limits**: Claude's 5-hour and weekly windows and Codex's weekly window,
  with reset times,
* when an agent asks for permission (run a command, edit a file…), the panel **takes
  over the screen** with the request and two big buttons: **Approve** and **Deny**.
  Answer on the panel or on the computer, whichever is closer — the first answer wins.

<p align="center"><img src="../images/ai.png" alt="AI page" width="640"></p>

Nothing here is on by default. Open the app's **AI** section.

## Show the page

Turn on **Show the AI page**. (You can also reorder it in **Pages**.)

## Live sessions and approvals

* **Claude Code:** turn on **Connect Claude Code**. PandaDeck adds a few *hooks* to
  `~/.claude/settings.json` so Claude Code tells the app what it's doing. Your existing
  settings and hooks are kept (a backup is saved next to the file).
* **Codex:** turn on **Connect Codex**. Same idea, in `~/.codex/hooks.json`.

Restart any open Claude Code / Codex sessions so they load the hooks. Turning the switch
off removes exactly what PandaDeck added.

Questions an agent asks *you* (multiple choice, plan approval) show as **"needs you"** on
the panel, but are answered in the terminal — only yes/no permission requests take over the
screen.

## Usage meters

* **Claude:** click **Connect Claude**. If the Claude Code CLI is installed, PandaDeck runs
  `claude setup-token` for you (a browser window asks you to authorize); otherwise run it
  yourself in a terminal and paste the token. The app checks your limits once a minute
  with the smallest possible request (one token on the cheapest model).
* **Codex:** click **Connect Codex**. PandaDeck reads the login the Codex CLI already
  saved on this computer (`~/.codex/auth.json`) — run `codex login` first if you haven't.

Tokens are stored only on your computer, in the app's settings folder, readable only by
your user account.

## Bonus: AI-drawn button pictures

With Claude Code or Codex installed, any deck button can get a picture drawn by the AI:
see [✨ Generate a picture with AI](04-deck.md#-generate-a-picture-with-ai). This works
even if the AI page itself is switched off.
