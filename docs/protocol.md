# PandaDeck link protocol

The desktop app talks to the panel over **USB** (primary, plug and play) or
**Wi-Fi** (optional). Both carry the same JSON payloads; only the framing differs.

## USB (CDC serial)

The panel enumerates as a composite device: HID keyboard + consumer control +
a CDC serial port. VID `0x303A` (Espressif), product string contains
`PandaDeck`. The host opens the CDC port at any baud rate (USB CDC ignores it;
**never 1200 baud**, that reboots the ESP32-S3 into its ROM bootloader).

The same port also carries the firmware's plain-text log lines, so binary
frames are marked with a magic prefix and anything outside a frame is log text
(the host may print or ignore it).

```
frame := MAGIC(3) TYPE(1) LEN(4, little-endian u32) PAYLOAD(LEN)
MAGIC := 0x1B 'P' 'D'
```

Every request from the host gets exactly one reply frame whose TYPE is the
lowercase of the request TYPE. One request in flight at a time. Max payload
is 512 KB. A reply that doesn't arrive within the timeout means "panel
busy/rebooting"; the host retries later.

| Host → panel | Payload | Reply | Reply payload |
|---|---|---|---|
| `H` hello | JSON `{"app":"pandadeck","ver":"1.0.0"}` | `h` | JSON panel info (below) |
| `S` sync | JSON snapshot (same as `POST /api/sync` body) | `s` | JSON (same as the `/api/sync` response: `ok`, `fw`, `boot`, `icons`, `events`) |
| `I` image | JSON header, `\n`, then raw pixels | `i` | JSON `{"ok":true}` or `{"ok":false,"error":"..."}` |
| `C` config | JSON settings (partial update, below) | `c` | JSON `{"ok":true,"settings":{...},"reboot":false}` |
| `U` update | `{"begin":{"size":N,"md5":"hex"}}` / raw chunk / `{"end":true}` | `u` | JSON `{"ok":true,"written":N}`; after `end` the panel reboots |
| `P` ping | empty | `p` | empty |

The `U` frames: first a frame whose payload starts with `{` = JSON begin;
then data frames with TYPE `D` (reply `d` `{"ok":true,"written":N}`), max
64 KB each; then `U` with `{"end":true}`.

### Panel info (`h` reply, also `GET /api/info` subset)

```json
{"app":"pandadeck","fw":"1.0.0","boot":1234,"board":"panda-touch",
 "wifi":{"configured":true,"connected":true,"ip":"192.168.1.50","ssid":"..."},
 "settings":{"pages":["deck","music","hud"],"brightness":100,"flip":false,"tflip":false},
 "features":["usb","wifi"]}
```

`features` lists optional firmware features compiled in; the app hides
settings for features the firmware lacks.

### Image header (`I`)

```json
{"kind":"icon","key":"app3","w":56,"h":56,"tag":""}
{"kind":"icon","key":"art","w":248,"h":248,"tag":"2afdb03a"}
{"kind":"backdrop","w":200,"h":108,"tag":"2afdb03a"}
```

`icon` = RGB565A8 (w*h*2 RGB565 little-endian, then w*h alpha), max 320x320.
`backdrop` = RGB565 little-endian, max 400x216; the panel scales it to the
800x432 page.

### Settings (`C`)

Partial: only the keys present change. Persisted in the panel's NVS.

```json
{"pages":["ai","deck","music","hud"],
 "wifi":{"ssid":"Home","pass":"secret"},        // {"ssid":""} forgets Wi-Fi
 "brightness":100, "flip":false, "tflip":false,
 "name":"PandaDeck"}
```

`pages` is the ordered list of tabs to show. Known ids: `ai`, `deck`,
`music`, `hud`. Unknown ids (pages this build doesn't have) are ignored;
an empty list falls back to `["deck"]`.

## Wi-Fi (HTTP)

Same payloads over HTTP on port 80, every request carrying the panel's token
in `X-Panda-Token` (the token is generated by the panel on first boot and
handed to the app over USB in the `h` reply as `"token"` — never shown or
sent over Wi-Fi unauthenticated).

| | |
|---|---|
| `GET /api/info` | panel info |
| `POST /api/sync` | snapshot in, events out |
| `POST /api/icon?key=&w=&h=&tag=` | multipart image |
| `POST /api/backdrop?w=&h=&tag=` | multipart image |
| `POST /api/config` | settings JSON |
| `POST /update` | multipart firmware |

## Snapshot (`S` / `POST /api/sync`)

Every key is optional; a missing section means "not available" and the page
shows its empty state.

```json
{"t": 1792523303, "boot": 1234, "ack": 17,
 "sessions": [...], "perms": [...], "usage": {...},
 "pc": {...}, "lab": {...}, "media": {...}, "deck": {...}}
```

See `firmware/PandaDeck/model.cpp` (`model_parse`) for every field, and
`tests/fixtures/snapshot.json` for a full example.

Events the panel returns (`events` array): `{"seq":N,"k":"cmd","a":"media:next"}`
and `{"seq":N,"k":"perm","id":"...","a":"allow"}`. The host acknowledges the
highest processed `seq` with `"ack"` (and the panel `boot` it refers to) in
its next snapshot; unacknowledged events are re-sent.
